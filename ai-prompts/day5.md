# Day 5 Prompt Log

## Prompt 1

Read the Day 5 ChatOps requirements and identify the minimum secure artifacts needed for Slack signature verification, background Slack handling, tool calling, permissions, audit logging, and offline tests.

## Prompt 2

Implement an offline-safe ChatOps handler that can answer API health, ingestion count, and failing pod questions while preserving a production-shaped tool boundary.

## Prompt 3

Add a three-tier permission model where READ actions run automatically, WRITE actions require a one-time confirmation token, and DESTRUCTIVE actions are denied and audit logged.

## Prompt 4

Create tests that do not require Slack, Anthropic, Kubernetes, or Prometheus credentials, but still verify the security and behavior contracts.
